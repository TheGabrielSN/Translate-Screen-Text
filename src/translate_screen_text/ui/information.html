Guia rápido

Como funciona a tradução

A aplicação permanece ativa em segundo plano aguardando o atalho global configurado.

  1. Pressione o atalho enquanto o jogo estiver visível.
  2. Selecione uma área com o mouse ou use a captura de tela inteira, conforme definido nas configurações.
  3. A imagem é capturada e processada pelo OCR.
  4. O texto reconhecido é enviado ao provedor de tradução escolhido.
  5. O texto original recebe blur e a tradução é apresentada por cima.
  6. Pressione uma tecla, clique o mouse ou use o controle para limpar o overlay.

O print temporário é excluído após a tradução ser exibida. Use Ctrl+Shift+Q ou feche a janela principal para encerrar toda a aplicação.
